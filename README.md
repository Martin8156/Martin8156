Hi, I'm Martin! I recently graduated from UT Austin with a degree in Electrical and Computer Engineering, and I'm actively seeking full-time opportunities in software engineering and adjacent fields. My work spans full-stack development with some machine learning applications.

Some highlights from my project work:

* 🎓 [Computer-Application-for-Team-Formation-in-Capstone-Design](https://github.com/Martin8156/Computer-Application-for-Team-Formation-in-Capstone-Design) — my capstone project: a web application that automatically assigns students to Capstone Design projects. Professors upload CSVs of student and project needs, and a constraint-based solver built on **Google OR-Tools** returns optimized team matches with quality metrics. **React** frontend, **Python/Tornado** backend, **NumPy/pandas** data processing.
* 🛠 [Engineering-Checkout-Center](https://github.com/Martin8156/Engineering-Checkout-Center) — a full-stack web app for managing a shared pool of ECE lab hardware, with user auth, project management, and live availability tracking. **React** frontend, **Python/Flask** backend, **MongoDB Atlas** database, and deployed with **Gunicorn on Heroku**
* ⚡ [Pokemon-Auction-Simulator](https://github.com/Martin8156/Pokemon-Auction-Simulator) — a real-time, multi-client auction platform written in **Java** with a **JavaFX/FXML** UI. Bids are broadcast instantly to every connected client using the **Observer pattern**, with multithreaded socket networking. **Gson** JSON serialization, automatic auction lifecycle management, and data stored in **MongoDB Atlas**.
* 🤖 [BERT-Punctuation-Restoration](https://github.com/Martin8156/BERT-Punctuation-Restoration) — fine-tuned a **BERT** model for punctuation restoration using **PyTorch** and the **Hugging Face** ecosystem (`transformers`, `datasets`, `evaluate`).
* 🔐 [Label-Inference-on-Feature-Subsets](https://github.com/Martin8156/Label-Inference-on-Feature-Subsets) — a **differential privacy** analysis exploring label inference from feature subsets, using **scikit-learn** (Random Forests, pipelines, GridSearchCV), **pandas**, and **matplotlib/seaborn** on the UCI Adult dataset.
